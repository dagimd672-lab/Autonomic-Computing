Chapter Two

MAPE-K
Architecture

The engine of every autonomic computing system

The MAPE-K Loop

KNOWLEDGE
M
MONITOR
A
ANALYZE
P
PLAN
E
EXECUTE
Continuous feedback loop for self-management

How the Loop Works

1

Sensors (Monitor)

Collect data about system state and environment.

2

Analysis Engines (Analyze)

Spot problems or opportunities in the data.

3

Planning Modules (Plan)

Decide the best course of action using policies.

4

Actuators (Execute)

Execute the plan through software or hardware changes.

The Four Self-* Properties (1)

Self-Configuration

Automatically configures itself when environment changes. New servers get provisioned with correct OS and software.

Self-Healing

Detects, diagnoses, and recovers from faults automatically. Crashed microservices restart.

The Four Self-* Properties (2)

Self-Optimization

Continuously monitors performance and tunes resources. Auto-scaling adds VMs.

Self-Protection

Detects and repels attacks while isolating failures. IDS updates firewall rules.

Auto Isolation

Misbehaving devices are isolated automatically before causing wider damage.
